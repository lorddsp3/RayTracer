### heres a build guide

> > Clone the code and move to directory

```
git clone https://github.com/lorddsp3/RayTracer
cd RayTracer
```

> > (only run once)

```
cmake -S . -B build
```

> > (to compile changes)

```
cmake --build build
```

> > Execute binary

```
./build/raytracer
```
